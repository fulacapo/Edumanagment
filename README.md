# EduManage Software Pro

This repository contains the source code for the EduManage Software Pro application.

## Run Locally

**Prerequisites:** Node.js

1.  Install dependencies:
    ```bash
    npm install
    ```
2.  Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key (if applicable).
3.  Run the app:
    ```bash
    npm run dev
    ```

## Deployment

To build for production:
```bash
npm run build
```
